# 🛒 Furniro - eCommercew Website Furniro is a modern, pixel-perfect, and fully responsive eCommerce website template built using pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. This project features key online shopping pages such as the **Shop Page** and **Cart Page** with active calculations and sleek user interactions. --- ## 🌟 Features - **Pixel-Accurate Design:** Built precisely according to Figma design specifications. - **Fully Responsive Layout:** Optimized for Desktop, Tablet, and Mobile screens. - **Dynamic Cart Interactions:** - Real-time Subtotal and Total price calculations upon quantity updates. - Delete item functionality with updated cart balance. - **Interactive UI Components:** - Mobile Hamburger Menu navigation. - Interactive Filter & Sorting Bar on the Shop page. - Product hover overlay options (Add to cart, Share, Compare, Like). - Toast notifications when items are added to the cart. - **Newsletter Subscription:** Client-side validation for email inputs. --- ## 📁 Project Structure ```text furniro-ecommerce/ │ ├── images/ # All image assets (Logo, Banners, Products) │ ├── logo.png │ ├── shop-banner.jpg │ ├── cart-banner.jpg │ ├── asgaard-sofa.png │ ├── product-syltherine.jpg │ ├── product-leviosa.jpg │ ├── product-lolito.jpg │ └── product-respira.jpg │ ├── index.html # Homepage ├── shop.html # Product Shop / Grid Page ├── cart.html # Shopping Cart Page ├── style.css # Main Stylesheet (Shared across pages) ├── script.js # Vanilla JavaScript Functionality └── README.md # Project Documentation
